# 原生键鼠注入助手（被控端）

spark-chat「远程桌面 · 双开自连」的**真·跨机控制**一环。

浏览器 JS 无法向操作系统注入键鼠，因此被控端需要本机原生进程来完成真实输入。
链路：**控制端 →(WebRTC)→ 被控端浏览器 →(localhost WS :17890)→ 本助手 → 真实 OS 鼠标/键盘**。

## 运行
```bash
cd native-assistant
npm install        # 已装可跳过
npm start          # 监听 ws://127.0.0.1:17890
```

## 使用
1. 被控机运行 `npm start`，保持助手常驻。
2. 被控端浏览器打开「远程协助 → 远程桌面 → 我是被控端」，连接后打开「启用原生键鼠注入」开关。
3. 开关显示「助手已连接」即代表真实输入链路打通：控制端的光标/点击/拖拽/滚轮/键盘会直接驱动被控机的系统。

## 说明
- 依赖 `@nut-tree-fork/nut-js`（原生模块，已验证可在 Node 22 / Windows 安装）。
- 坐标由控制端以归一化 (0~1) 发送，助手按本机真实分辨率 `screen.width()/height()` 换算后注入。
- 受支持的特殊键：Enter / Backspace / Tab / Escape / Delete / 方向键；其余可见字符走 `keyboard.type`。
- 被杀毒软件拦截时，请将本目录加入白名单。
